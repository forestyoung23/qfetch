# 客户端操作流程

已验证环境：macOS夸克7.4.2.1020，内置网盘2.5.40。下表中的文字是定位线索，不要求版本号相同。优先使用当前窗口中可读的控件、角色和名称；缺少语义信息时使用当前截图定位。不要保存或复用元素编号、绝对坐标及内部`uccd://`页面地址。

## 无人值守前的窗口自检

默认使用普通窗口。先通过应用菜单或工具提供的窗口能力将夸克网盘置前；菜单显示“退出全屏幕”时，退出全屏并重新获取窗口，再执行下表的搜索步骤。以输入框和搜索结果真实变化确认操作能力，不只检查截图或辅助功能树是否可读。

本机在外接显示器、夸克全屏时曾出现：辅助功能树可读，点击报`noWindowsAvailable`，输入没有变化；通过“显示 → 退出全屏幕”恢复了搜索输入。此错误不能直接诊断为锁屏。窗口异常的优先恢复顺序为：刷新当前窗口 → 通过菜单置前并退出全屏 → 重新获取窗口与控件 → 重试当前步骤一次。其他Agent可用等价的原生窗口操作完成同一恢复；不固定显示器编号或位置。

普通控件恢复后，模态窗口仍应单独重新定位。恢复失败则报告一次具体环境阻碍，保留任务和文件；不要反复请求用户代点每一步，也不要在没有新状态的情况下重复同一输入。无人值守依赖有效登录及可操作的桌面，不修改系统锁屏或安全设置来满足这一条件。

## 官方技能不可用时的分享转存

先按技能入口检查官方技能；以下仅为官方技能不可用时的UI路径。用户提供分享链接时，使用客户端提供的链接打开或转存入口；若客户端没有该入口，可在其内置浏览器打开用户提供的夸克分享链接，并使用页面上的“打开客户端/保存到网盘”等实际入口。具体入口需核对当前界面，此分享流程尚未单独实测。

核对分享者、文件名及目录内容；有提取码时只在夸克的对应访问界面输入。先检查自己的网盘中是否已有同一文件，只选择需要的文件并确认保存目录，观察转存成功后在自己的网盘定位该文件，再执行下载步骤。分享失效、缺少提取码或无法确认目标时报告具体阻碍；不重复提交转存，也不转存整个分享来代替单文件选择。

## 从文件到下载任务

| 步骤 | 优先路径 | 必须观察到的结果 |
|---|---|---|
| 打开网盘 | 客户端“网盘”入口；已在网盘则复用当前窗口 | 网盘文件列表或传输界面 |
| 查找文件 | 已有官方技能定位结果时直接按其路径找文件；否则激活顶部“搜网盘、搜全网或输入网址”；全选输入文件名；点击浮层中的“搜索网盘文件” | 搜索结果已更新为本次关键词，不只是输入框文字变化 |
| 核对选择 | 比对完整文件名、大小和网盘位置；需要时打开“详情信息” | 选定唯一目标；不要双击视频触发播放 |
| 检查重复 | “传输 → 下载”检查进行中及已完成记录，核对本次文件与目标路径 | 已有任务则复用，不再右键下载 |
| 提交下载 | 文件行右键菜单“下载”；版本提供等价工具栏按钮时也可使用 | 出现目录选择器，或已有明确目标目录的新任务 |
| 选择目录 | 按下节操作系统目录选择器 | 当前目录确为目标目录，再确认“打开/选择/保存” |
| 确认启动 | “传输 → 下载 → 正在下载”定位刚才的文件 | 任务正在传输或明确排队，保存路径正确；仅看到任务计数增加不够 |

本地登记完成但上次尚未提交下载时，确认客户端没有相应任务、目录选择器和下载文件后，继续首次提交；本地记录本身不是已提交证明。

搜索浮层未出现时，先重新激活输入框。按回车只有在结果确实更新后才算成功；不要把输入框显示的新文字当作搜索已提交。若结果同名，结合位置及详情确定来源，不能只选第一项。

## 系统目录选择器

1. 先读取目录选择器的当前状态，确认它已经出现并处于活动状态；不要把“打开选择器、输入路径、确认”连续盲发。
2. macOS优先使用`⌘⇧G`打开“前往文件夹”。等待新窗口出现后，重新获取当前模态窗口的操作目标，定位路径文本框。工具支持直接设置文本时优先设置完整绝对路径；否则激活后全选并粘贴或键入。不要继续用之前主窗口的输入目标。
3. 读取文本框确认完整路径实际写入，再按回车。再次读取选择器，确认已进入预期目录；必要时查看位置栏或目录路径，再点击“打开/选择/保存”。路径文本框仍在时，说明还没有完成跳转。
4. 如果输入没有变化，重新获取当前应用/模态窗口的目标，激活路径框，并改用工具支持的另一种输入方式（如直接设置文本、粘贴或键入）。每次都核对实际文字。语义定位失败时，用新截图定位输入框，注意工具的坐标缩放约定。
5. 一次重新定位与一次替代输入仍失败时，先尝试在选择器中逐级导航到目标目录。输入和导航都不可用时，报告具体环境阻碍，保留当前对话框；不确认错误目录，不重复提交下载，也不把日常目录选择变成人工确认步骤。

本机已自动完成一次“重新定位模态窗口 → 直接设置路径 → 跳转 → 确认下载”的小文件测试。它是已验证的优先路径，不代表其他Agent的输入后端或未来客户端版本也已通过相同测试。

## 观察、暂停与恢复

- 每次操作后刷新窗口状态，再决定下一步。窗口、焦点或用户操作改变后重新获取控件。按预计剩余时间观察，通常间隔15–30秒；排队或大文件可放宽至60秒，避免连续截图空转。
- 单个任务的暂停按钮位于任务行；用名称、提示或当前截图区分暂停、继续和取消。暂停后应出现“已暂停”；恢复后应从原进度继续，不能新建任务。
- 客户端重启或Agent换会话后，先通过文件来源、名称和保存目录定位原任务，再恢复。这个恢复步骤需要当次验证，不能用一次普通暂停测试代替重启恢复证明。
- `.qkdownloading`临时文件可能含任务后缀或预分配空间。本地文件增长仅作辅助，不能单凭大小判断传输完成。
- 速度长期很低或失败时，读取本次任务的原因并报告。不要自动购买会员、关闭代理或改客户端设置；不要仅凭会员接口字段判断客户端下载能力。

## 完成与界面变化

“已完成”列表必须出现本次任务，并核对其保存目录；可通过任务菜单的详情或“打开所在文件夹”确认。最终文件名应与选定文件一致，然后运行本地`check`命令。记录了精确大小时必须匹配；客户端只提供约数时，报告实际文件大小和`size_verified=false`，不将客户端完成等同于精确大小已核验。

若升级改变标签或布局，在当前窗口寻找含义等价的控件并验证同一结果；只有当前步骤不匹配时才扩展检查。无法确认下载对象、目标目录或操作含义时停止该步，说明具体阻碍，不盲点旧位置，不退回网页API下载。
