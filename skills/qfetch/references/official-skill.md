# 官方技能准备

本文件只在需要官方技能且尚未就绪时读取。搜索、元数据和分享转存优先使用官方技能，实际下载始终由客户端完成。不要使用官方CLI下载来替代客户端下载。

## 发现与安装

1. 检查所在Agent的技能清单或全局技能目录，找到`quarkclouddrive`后读取其`SKILL.md`；不硬编码某个Agent的安装路径。已安装时复用，不创建第二份，也不复制其他人的授权配置。
2. 缺少时，优先使用所在Agent支持的技能安装机制，从夸克官方发布来源安装。当前本机官方安装脚本使用的发布配置为：`https://open-api-drive.quark.cn/agent/v1/skill_config?req_id=<本次时间戳>`。从响应配置中读取`qkPan`下载地址和`qkPanVersion`版本，不固定版本或下载包地址。
3. 使用官方配置指向的HTTPS包，核对来源和包结构，安装到当前Agent的全局技能目录。2026-10-26验证该配置返回1.0.25版本、`pdds.quark.cn`托管的发布包；今后以可核验的官方发布为准。若安装机制不能直接接收该包，可下载检查后按其目录规范安装，不能随意使用同名第三方仓库。
4. 读取安装后的官方`SKILL.md`，按其中的当前初始化及安装检查要求完成自检；本次核对的版本要求运行包内`scripts/install.sh`。遵循其运行时依赖、授权、公共参数及结果展示规则，不在QFetch中复制并维护另一套CLI协议。
5. 验证技能与CLI已可用。部分Agent需要刷新技能清单或到下一轮才识别新安装；未识别前不能假定安装已经可用。安装失败、来源无法核验或安装受环境限制时，说明具体原因并转用客户端，不循环安装。

自动安装按当前Agent的权限机制执行，不能规避环境审批。新账号授权若需要用户扫码或确认，优先检查已登录客户端能否继续本次任务；不要为了使用首选工具而要求用户重复登录。

## 业务操作与客户端交接

按官方技能的当前说明搜索、读取详情或检查分享；已满足要求时复用已有结果。无需列出整个网盘或在两种工具中重复检索。官方搜索无结果不等于工具不可用，不在没有新线索时反复换工具重查。

分享转存前核对自己的网盘是否已有目标，只处理所需文件。转存超时或结果不明确时先检查实际网盘状态，再决定是否重试或切换UI，避免重复转存；不并行提交两次转存。

将账号、网盘路径、完整文件名和精确大小交给客户端下载流程。官方技能返回的文件ID与客户端网页ID可能不是同一格式；不要转换或混用。在UI中按路径、文件名和大小核对唯一目标，再提交下载。

此分工基于结构化能力与本机已有测试选择：官方浏览与元数据读取可用，客户端GB文件下载更快。官方分享转存尚未在本次流程中单独实测，应以当次结果确认成功，不宣称所有操作均已验收。
