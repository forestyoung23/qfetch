# 官方技能准备

本文件只在需要官方技能且尚未就绪时读取。搜索、元数据和分享转存优先使用官方技能，实际下载始终直接操作客户端完成。官方技能的`download`命令及下载指引不适用于QFetch流程；安装或读取其说明不改变[技能入口的下载执行边界](../SKILL.md#下载执行边界必须遵守)。

## 发现与安装

1. 检查所在Agent的技能清单或全局技能目录，找到`quarkclouddrive`后读取其`SKILL.md`；不硬编码某个Agent的安装路径。已安装时复用，不创建第二份，也不复制其他人的授权配置。
2. 缺少时，优先使用所在Agent支持的技能安装机制，从夸克官方发布来源安装。当前本机官方安装脚本使用的发布配置为：`https://open-api-drive.quark.cn/agent/v1/skill_config?req_id=<本次时间戳>`。从响应配置中读取`qkPan`下载地址和`qkPanVersion`版本，不固定版本或下载包地址。
3. 使用官方配置指向的HTTPS包，核对来源和包结构，安装到当前Agent的全局技能目录。2026-10-26验证该配置返回1.0.25版本、`pdds.quark.cn`托管的发布包；今后以可核验的官方发布为准。若安装机制不能直接接收该包，可下载检查后按其目录规范安装，不能随意使用同名第三方仓库。
4. 读取安装后的官方`SKILL.md`，按其中的当前初始化及安装检查要求完成自检；本次核对的版本要求运行包内`scripts/install.sh`。遵循其运行时依赖、授权、公共参数及结果展示规则，不在QFetch中复制并维护另一套CLI协议。
5. 验证技能与CLI已可用，再按下一节检查账号授权；安装成功不能作为授权成功的证据。部分Agent需要刷新技能清单或到下一轮才识别新安装；未识别前不能假定安装已经可用。安装失败、来源无法核验或安装受环境限制时，说明具体原因并转用客户端，不循环安装。

自动安装按当前Agent的权限机制执行，不能规避环境审批。

## 账号授权（安装后必须检查）

官方技能授权与夸克客户端登录相互独立。先读取安装后的官方`SKILL.md`及其授权文档，按其当前规定检查状态，不读取或复制客户端Cookie、其他机器的令牌和授权配置。

- 已有有效授权时复用，不要求重新登录。
- 安装检查提示首次绑定、账号未授权，或业务命令返回未授权/认证过期时，立即向用户说明：“夸克官方技能已安装，但还需要你完成账号登录授权，才能查询和转存网盘文件。客户端登录不能代替这次授权。”同时按官方要求展示实际提示。不要重复业务命令或静默改走客户端。
- 首次绑定若官方流程要求用户先回复“授权”，展示该引导并等待回复；用户确认后启动官方登录流程。若用户已经明确要求登录授权，或官方文档规定认证过期后直接引导登录，则告知用户后启动该流程，不重复索要同一确认。
- 使用官方登录命令打开本次授权页面，将官方返回的必要操作入口展示给用户，请用户亲自登录、扫码或确认。进入等待授权状态；未完成前不执行依赖授权的查询和转存，不把等待期间用于探索替代认证方式。必要时结束当前回复，等用户完成后继续；不能把等待超时当作用户同意或拒绝。
- 只有官方登录结果确认成功，才继续原任务；按官方当前要求展示授权结果及必要提示。用户说“已完成”但结果仍未成功时，说明实际状态，不宣称已授权。
- 用户取消、拒绝或授权超时时，报告具体状态，不循环启动登录。用户明确选择不授权或改用客户端后，才使用已登录客户端继续；否则保留任务，等待用户决定。安装或能力本身不可用时仍可按上一节使用客户端。

首次绑定的简短引导可为：“官方技能已安装，需要你完成一次账号授权。请回复‘授权’，我会打开官方登录页面；完成后继续刚才的下载任务。”以安装版本的实际授权要求为准，不要求用户把密码或Cookie发到对话中。

## 业务操作与客户端交接

按官方技能的当前说明搜索、读取详情或检查分享；已满足要求时复用已有结果。无需列出整个网盘或在两种工具中重复检索。官方搜索无结果不等于工具不可用，不在没有新线索时反复换工具重查。

分享转存前核对自己的网盘是否已有目标，只处理所需文件。转存超时或结果不明确时先检查实际网盘状态，再决定是否重试或切换UI，避免重复转存；不并行提交两次转存。

目标已定位或转存成功后，立即转入[客户端操作流程](client-workflow.md)，将账号、网盘路径、完整文件名和精确大小交给该流程。不要继续尝试CLI下载、查找直链或登录网页版网盘点击“下载”唤起客户端。官方技能返回的文件ID与客户端网页ID可能不是同一格式；不要转换或混用。在客户端UI中按路径、文件名和大小核对唯一目标，再提交下载。

此分工基于结构化能力与本机已有测试选择：官方浏览与元数据读取可用，客户端GB文件下载更快。已实际完成一次按文件ID转存单个电影文件；仍以当次任务成功结果为准，不将单次成功推广为所有分享均可用。
