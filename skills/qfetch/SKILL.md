# 夸克下载

## 下载执行边界（必须遵守）

下载、暂停与恢复只能直接操作夸克客户端。官方`quarkclouddrive`仅用于账号查询、检索、元数据、分享转存及所需安装授权；其`download`命令不适用。不尝试CLI下载、获取直链、网页/API下载或网页版“下载”唤起客户端。用户明确改变下载方式时，说明超出本流程后按新请求处理。

公开资源检索只使用Google；已有明确分享或原任务直接核验复用。只转存最终选择的文件，不同时通过两种方式操作同一转存任务。来源和版本证据不足时不能推进。

## 阶段与按需读取

| 阶段 | 读取与执行 | 推进依据 |
|---|---|---|
| 客户端自检 | 首次检索或转存前读取[客户端能力检查](references/client-workflow.md#先验证本会话的客户端能力)；仅检索或转存请求可跳过 | 本会话能够观察并输入 |
| 多资源清单 | 多项请求读取[两项流水执行](references/batch-workflow.md) | 身份明确、清单去重 |
| 资源发现 | 只有名称时读取[Google检索](references/web-search.md)，预算和浏览器异常恢复均以该文档为准 | 来源、分享与文件已核验 |
| 视频选择 | 读取[资源选择](references/resource-selection.md)，记录候选并运行`select_resource.py`；指定文件或自定义偏好按用户要求 | 选择器通过且有现场核验证据 |
| 账号与转存 | 优先官方技能；安装、授权及降级条件统一见[官方技能准备](references/official-skill.md) | 目标已在网盘唯一定位；已有结果直接复用 |
| 本地准备 | 读取[本地检查](references/local-checks.md)，执行`prepare` | 来源、目标目录与空间通过检查 |
| 提交与观察 | 按[客户端流程](references/client-workflow.md)提交；窗口恢复、观察频率和停滞处理以该文档为准 | 同一文件及保存目录的任务已出现 |
| 完成 | 按[完成核对](references/local-checks.md#完成核对)执行`check` | 客户端完成与本地结果均通过 |

某阶段失败不重走已成功的阶段；提交结果不明时先核对原任务，不重复提交。`prepare`冲突时保留现场，不删除记录或另建目录规避。客户端恢复预算与检索预算分开计时，换工具或切换清单项不能重置同一故障预算。

最终逐项报告来源、状态、路径和未验证项；要求下载完成时跟进至完成或明确阻碍，不把转存、排队或任务提交当作完成，也不承诺会话结束后自动监控。
