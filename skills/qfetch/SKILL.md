# 夸克下载

只走夸克路线，每次处理一个文件。目标是将选定文件下载到本地并确认完成。

## 定位文件

读取本机官方`quarkclouddrive`技能，按它的实际能力和授权流程查找文件、检查分享、转存选定文件。片名或文件名有歧义时先确认；找到满足用户要求的可用文件即可，不扩展成全网找源或版本评分。只转存需要的文件。

复用本机授权，不保存Cookie、授权码或临时下载地址。确认官方客户端已登录，Agent可以实际观察和操作窗口。依赖缺失或UI不可用时，说明缺少的条件并停止下载操作。

## 开始下载

1. 核对最终文件名和精确字节大小。检查客户端是否已有同一文件的任务；存在时操作原任务，不再次转存或提交下载。
2. 每个文件使用一个独立的本地目录，先确认磁盘已挂载，再创建目录。保留已有文件，不覆盖或删除。检查其他客户端下载任务的空间占用；空间不足时停止。
3. 用本技能目录中的脚本登记选择并检查空间：

```bash
python3 "$SKILL_DIR/download.py" prepare --directory "$DIR" --filename "$FILENAME" --size "$BYTES"
```

`ready`只表示本地检查通过，尚未启动下载。`existing_task=true`表示有既有记录，先核对原客户端任务；`file_present`只表示同名同大小文件存在，先核对是否就是所需文件。`needs_attention`时先处理原因，不另建记录规避检查。

脚本只保存文件名和大小，使用保守空间规则：目标盘至少有两倍文件大小加5GiB可用空间；目标盘与系统盘不同时，系统盘也检查同一规则。它不预留磁盘空间，也不统计其他任务的未来占用。

4. 在夸克客户端核对目标文件，下载到`$DIR`。以最新窗口状态操作，只控制本次任务，不使用“全部暂停/开始”。出现失败时保留原任务和文件，根据实际原因处理；不自动购买会员或修改代理。

## 查询与完成

查询本地文件：

```bash
python3 "$SKILL_DIR/download.py" status --directory "$DIR"
```

进度、速度、失败原因和暂停状态以当前客户端窗口为准。脚本记录或临时文件的预分配大小不能证明任务正在运行或已完成。暂停、恢复和重启后都先定位原任务。下载中观察可用空间，不足时通过UI暂停本次任务。

仅在客户端实际显示本次任务完成后运行：

```bash
python3 "$SKILL_DIR/download.py" check --directory "$DIR" --client-completed
```

`complete`表示已确认客户端完成，且最终文件存在、大小与所选文件一致；不代表文件内容或可播放性经过验证。报告实际状态和保存路径。

用户只要求开始下载时，在观察到任务已启动后报告进度；要求下载完成时，持续跟进到完成或遇到明确阻碍。无法继续观察时保留任务，如实说明当前状态，不承诺会话结束后自动监控或通知。
