# 换机器与数据迁移

只分享技能：复制/安装代码目录即可。每位使用者在自己的数据目录初始化配置，独立安装依赖并授权夸克。安装器不包含或复制媒体、账号和任务记录。

自己的第二台机器：若只需要新下载，也重新初始化；如果需要继续使用旧媒体库，先挂载存储并核对已有文件，不在空账本中盲目重复下载。

完整迁移已有任务：

1. 在旧机器停止相关下载器，确认不再写入，保留原文件及原账本备份。
2. 复制数据和账本，核对文件大小、散列、磁盘容量及实际挂载位置。任务记录和固定清单可能包含绝对路径，不能照搬旧config.json的路径或设备号。
3. 在新机器建立配置。要使用已迁移的账本，可初始化时传 `init --state-root /新机器/账本目录`。确认state-root、transfers和library的实际位置；不要通过忽略设备检查来启动。
4. 已完成文件：由Agent根据已验证来源与实际文件重新核对登记记录中的成片路径，执行lookup --verify；验证通过前不创建新下载。原机可继续保留备份。
5. 未完成任务：客户端格式、任务ID和临时文件续传兼容性需要单独验证；本版本不自动改写固定清单或迁移客户端下载任务。无法确认兼容时保持停止，不删除旧部分文件。

当前自动支持的是代码安装与新机器初始化；已有媒体、任务及客户端续传迁移需要上述核对，不宣称一键迁移已实现。不同机器独立授权，不分享网盘登录配置。
